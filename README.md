# 豆豆火力岛：爆破行动

糖果风格的第一人称 5v5 爆破游戏。你与四名豆豆 AI 队友对抗五名 AI，单人离线运行，无需账号或服务器。

[在线游玩](https://ericcui-debug.github.io/bean-frontier/) · [离线版](site/index.html)

## 规则

先赢五回合获胜，最多九回合；第四回合结束后换边，比分跟随队伍。开始时可选攻守，默认进攻。每回合购买准备 15 秒、交战 90 秒。准备阶段不能移动和射击，可购买装备、转镜头与选择 A/B 战术。

进攻方在任一包点连续按住互动 3 秒安包；安包后倒计时 35 秒。防守方连续按住互动 5 秒拆包。移动、射击、松开互动或离开范围会中断。恰好在截止时间完成仍有效。未安包时进攻方全灭或时间耗尽为防守胜，防守方全灭为进攻胜；安包后进攻方全灭仍继续，由拆除或爆炸决定胜负。

每回合一条命，阵亡后观战队友，可切换队友与四倍速观战；AI 能接管掉落炸弹并独立结束回合。下一回合统一恢复生命，存活者保留装备，死亡者失去主武器与护甲。换边重置装备和经济。队友挡弹，但关闭友军伤害。

## 操作

- 电脑：WASD 移动，点击场景后鼠标转镜头，左键射击，右键切换精瞄，Space 跳跃，R 换弹，1 手枪、2 主武器，按住 E 安包/拆包，单次 E 拾枪/拾包，B 购买，Esc 暂停，F 全屏。
- iPhone/手机：左下摇杆小幅推动慢走、外圈跑动；右侧空白区转镜头。右开火键支持按住射击并拖动瞄准，两根手指可同时移动、瞄准、射击；左开火键供多指玩家使用。精瞄点按切换，跳跃、换弹和切枪独立。进入有效范围后按住互动安拆包，进度环显示剩余进度；单次互动拾取武器或炸弹。
- 准备期间用大卡片购买，或点击“一键推荐”。购买结束自动关闭，清空输入；关闭购买面板可转镜头，仍不能移动或开火。
- 暂停设置可调普通、精瞄和狙击灵敏度，按钮大小、透明度、30/60 FPS、瞄准减速辅助和音频。默认精瞄 60%、狙击 35%；辅助只减慢准星附近无遮挡敌人的转镜头速度，不自动瞄准、转向或开火。
- 横屏优先，开始时按浏览器能力请求横屏与全屏。Safari 不支持时仍可正常游玩，手动横屏即可；竖屏保留操作。失焦、切后台、旋转和触控取消会暂停并清空输入。

## 装备与经济

| 武器 | 价格 | 弹匣/备用 | 基础伤害 | 射击间隔 |
|---|---:|---:|---:|---:|
| 手枪 | 免费 | 12/60 | 20 | 0.24 秒 |
| 冲锋枪 | 1000 | 30/120 | 18 | 0.10 秒 |
| 步枪 | 2400 | 30/90 | 30 | 0.14 秒 |
| 狙击枪 | 3500 | 5/20 | 80 | 1.15 秒 |

所有角色生命 100，头部伤害两倍。护甲 600，降低身体伤害 20%。装备为手枪加一把主武器，死亡掉落主武器可拾取。开局资金 800，胜利 +3000、失败 +2000、击杀 +300、安包/拆包操作者 +300，上限 8000。AI 遵守同样的装备、弹药和经济规则。

小地图只显示地形、自己、队友和任务信息，不显示敌人位置。敌人受击且无遮挡时短暂显示血条。AI 依据视线、队友通报与炸弹事件推进、绕侧、守包及回防，失去视线后搜索最后见到位置，约三秒后遗忘。

## 本地开发与离线

```sh
npm install
npm run dev
npm run build
```

本地预览：`http://localhost:5180/`。构建生成自包含的 `Bean-Frontier.html`，可直接在浏览器离线打开。模型、字体、音乐、音效全部内嵌，不依赖 CDN。只有操作/音频设置存入本地；不保存对局。

原沙盒离线回退文件：`releases/Bean-Frontier-Sandbox-2026-10-05.html`。原版源码与脚本存于 `releases/sandbox-2026-10-05/`；原 Bean Blitz 项目未修改。

`window.render_game_to_text()` 返回只读状态；`window.advanceTime(ms)` 提供确定性时间推进。可修改状态的测试辅助 `window.__gameTest` 仅在 URL 带 `?test` 时启用。自动化仅连接 Codex 专用浏览器 `http://127.0.0.1:9333`，不会连接用户常用 Chrome。

手机默认 30 FPS，提供 60 FPS；渲染分辨率自动适配负载，低分辨率阴影与分频 AI 决策，物理固定 120 Hz。浏览器多点触控模拟不能代替实体 iPhone 的 Safari 手感、动态地址栏和性能验证。

没有联网、投掷道具、蹲趴、近战、建造或长期成长。第三方许可见 `licenses/`。

## 验证记录（2026-10-07）

`npm test` 检查共享地图与碰撞、即时命中、镜头、回合临界时刻、经济继承和团队 AI。`npm run test:route` 用实际键鼠事件走通购买、移动、跳跃、射击、换弹、切枪、安拆包及暂停；为可重复验证，安拆包和命中场景使用 `?test` 控制场景。`npm run test:mobile` 使用 CDP 多点触控事件检查双指与多指、持续互动、五种屏幕尺寸和最大按钮尺寸、安全区与旋转取消。另以正常 AI 模拟完整对局、掉包接管、自主安包/拆包和换边。

`npm run test:offline` 在断网浏览器打开正式 HTML 检查音频、字体、购买、战斗、回合复活与重开，并以离线测试场景验证死亡/掉包/观战；`npm run test:pages` 对线上 HTML 与已测试包逐字节比较并运行生产交互检查。实际截图与检查报告位于本地 `output/bomb-*`。

未进行实体 iPhone 测试，因此不保证特定机型的 30 FPS、温度耗电或 Safari 手感；全屏/横屏锁定取决于浏览器能力，失败时可手动横屏继续玩。
