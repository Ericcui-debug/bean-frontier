# 豆豆火力岛

[在线游玩](https://ericcui-debug.github.io/bean-frontier/) · [离线版](site/index.html)

Tiny Strike 的完整五图画面与单人爆破玩法，搭配豆豆角色和手机双指操作。开局默认 CT；也可选择 T。每方总计五人，玩家阵亡后观战存活队友，下一回合复活。没有联网、账号、排行榜或长期成长。

## 地图与规则

| 地图 | 大厅名称 | 特点 |
|---|---|---|
| Dustyard | 沙尘货场 | 沙地、市场、庭院与长线交战 |
| Frostline | 霜线基地 | 冰雪基地与服务隧道 |
| Neon Foundry | 霓虹铸厂 | 夜景、工业建筑和近距交战 |
| Harbor | 风暴港口 | 湿地、货箱与码头 |
| Citadel | 山巅堡垒 | 石材建筑、城墙和高台 |

先赢八回合，最多十五回合。准备六秒，交战115秒，C4计时40秒；安包持续3.2秒，拆包10秒，携带工具时五秒。T玩家默认携包；死亡后掉包，AI可接管。存活者保留枪械、护甲、工具及选中的武器，回合间补弹；死亡失去装备，重开整场清空装备与资金。

采用上游武器价格、伤害和经济：开局8000、上限16000。七种枪械、刀和高爆／闪光／烟雾三种投掷物；购买界面提供推荐装备，已有主武器时只补护甲。同款重复购买不扣钱。

## 电脑操作

WASD移动、鼠标转镜头、左键射击／按住投掷物后松开投掷、右键操作武器原生瞄准镜（AWP两档）、Shift慢走、Ctrl蹲下、Space跳跃／切换观战队友、R换弹、E按住安拆包或拾取C4、B购买、1–4选择主武器／手枪／刀／投掷物，重复4切换投掷物、Q上一把武器、Tab比分、Esc暂停、F全屏。

## 手机操作

左下摇杆小幅慢走、外圈正常跑动；右侧空白区滑动瞄准，右开火键按住开火并可同时拖动镜头（半自动枪按原射速重复扳机，桌面保持原半自动方式），另有左开火键。开镜、蹲下、跳跃、换弹、互动与四个武器槽独立操作。投掷物按住开火蓄力，松开投掷；取消、后台或暂停不会意外扔出。包点和掉落C4附近显示相应互动按钮。

开始时尝试横屏和全屏；Safari不支持时仍可正常游玩，竖屏显示横屏建议。暂停设置可调整普通／一档镜／二档镜灵敏度、按钮大小和透明度、30／60 FPS以及音乐和音效。旧设置自动迁移。旋转、失焦、切后台与任意触控取消均暂停并清空输入，恢复后点继续。

## 画面与离线

完整复用原地图建筑、装饰、程序化PBR颜色／法线／粗糙度／遮蔽纹理与天空环境。桌面启用HDR后期与MSAA，自动限制高分屏渲染到约200万像素、最高1.5倍分辨率，并按持续负载调整，目标60 FPS；贴图精度和地图内容保持不变。手机采用原生低档PBR、关闭HDR后期，保留MSAA和1–1.5倍渲染分辨率，默认60 FPS（可在设置选择30 FPS）。只在开始时构建当前地图，返回大厅释放地图和天空；恢复WebGL时重新烘焙地图与真实枪械材质。

`Bean-Frontier.html`包含五图、必要模型、字体和许可，不需要网络。复制单文件到电脑，可直接用支持WebGL2的浏览器打开。iPhone上建议使用在线地址；系统文件预览器对网页脚本的支持与Safari不同。

## 动作与命中

蹲下保留豆豆头脸和鞋的比例，下半身折叠、身体前倾，站立外形和角色尺寸保持不变。头身伤害按当前姿态的可见几何判定；AI瞄准当前躯干位置，失去视线后只保留最后见到的瞄准点。手机蹲姿按钮显示“蹲下”“站起”或“上方受阻”，移出低顶后可自动站起。


本地预览端口5180。自动化仅连接专用Codex Chrome `127.0.0.1:9333`；不启动或连接日常Chrome。`render_game_to_text()`和`advanceTime(ms)`可用；仅`?test`开放内部对象、固定种子与状态夹具。物理和回合以固定120Hz推进，渲染独立调度。
