# 豆豆火力岛：经典行动

[在线游玩](https://ericcui-debug.github.io/bean-frontier/) · [离线版](site/index.html)

第一人称、单人离线 5v5 战术游戏。玩家与四名 AI 队友对抗五名 AI。豆豆保持 80% 尺寸，场景、服装和枪械采用卡通写实美术。本版包含两个模式各自对应的完整战场。

## 两张地图

- **Assault · 工业仓库／救援**：参考 CS1.6 经典布局重做。室外街道、桥梁与救援区、仓库正门及后门、箱堆、内部楼梯与上层走道、人质房、屋顶、梯子和分支通风管形成不同突入路线。人质必须实际护送到室外。
- **Dust2 · 沙漠城镇／爆破**：参考 CS1.6 经典布局重做。保留 A 大道、双门、坑位、A 小道与楼梯、A 平台与斜坡、中路、中门、上下层隧道、B 隧道出口、B 门、窗口与平台，以及双方出生区域。

大厅选择地图或随机地图，整场固定。默认 Assault 反恐方；Dust2 默认进攻方。可在开始前选择另一阵营。重开保留当前地图，返回大厅后可另选。结构完整重做并非原地图文件的一比一移植；通风管与窄口按豆豆通行尺寸作必要适配。

区域、路线、高差及与参考结构的适配差异详见 [地图说明](MAPS.md)。

## 对局与装备继承

购买准备 15 秒，交战 180 秒；先赢五回合，最多九回合。第四回合结束后交换阵营，比分跟随固定队伍。

**只要存活，手枪、主武器、护甲、资金和当前武器槽都保留，换边也保留。** 下一回合恢复生命并补满弹药。死亡失去主武器和护甲，下一回合统一复活。整场重新开局才清空装备、资金和比分。只有操作与音频设置保存在设备，不保存对局。

已有主武器时，一键推荐只补护甲，AI 也不会自动换掉存活武器。主动购买另一主武器或拾枪会把旧枪掉在脚边；同款主武器不会重复购买扣钱。队友挡弹，但不会受到友军伤害。

### Assault 救援

反恐方互动让人质跟随，再次互动让其停留，可带领多人。四名人质中任意两名抵达救援区即获胜，操作者每名获得 300；人质不受伤、不挡弹。人质只走地面与楼梯，不钻通风管或攀梯；领队死亡后原地等待另一名反恐成员接管。守卫全灭反恐方胜；反恐全灭或超时守卫方胜。玩家死亡后 AI 仍能招募并完成护送。

### Dust2 爆破

进攻方在 A／B 包点连续互动 3 秒安放 C4；安放后倒计时 35 秒，防守方连续互动 5 秒拆除。移动、跳跃、开火、松手或离开范围中断进度。恰好在截止时完成有效。未安包时进攻方全灭或超时为防守胜，防守方全灭为进攻胜；安包后进攻方全灭仍继续比赛。死亡掉包后队友可接管。

每回合只结算一次。同刻双方全灭时，救援模式守卫胜；爆破模式未安包防守胜，已安包则继续 C4 计时。阵亡后可切换队友观战及四倍速观战。

## 操作

- **电脑**：WASD 移动，点击场景后鼠标转镜头；左键射击、右键切换精瞄；Space 跳跃、R 换弹、1／2 切枪、B 购买、Esc 暂停、F 全屏。E 点击带领／停止人质、开门、拾枪／拾包；按住 E 安拆包。
- **手机**：左摇杆小幅慢走、外圈跑动，右侧空白区滑动转镜头；右开火键按住射击并拖动瞄准，双指同时移动、瞄准、射击。保留左开火键；精瞄点击切换，跳跃、换弹、武器栏独立。
- **梯子与通风管**：面对梯子 W／S 或摇杆前推／后推攀爬，跳跃脱离。进入低矮通风管自动低姿与减速，有足够净空后恢复，不增加手机按钮。
- **互动**：人质与门点按；安拆包按住，界面显示进度。准备阶段可以购买和转镜头，不能移动或射击。购买结束自动关闭并清空输入。
- **设置**：普通／精瞄／狙击灵敏度、按钮大小与透明度、30／60 FPS、瞄准减速辅助、音乐和音效。默认精瞄 60%、狙击 35%；辅助仅减速，不自动瞄准或开火。
- **iPhone／Safari**：横屏优先，开始时按能力请求全屏和横屏，不支持时手动横屏即可。竖屏可操作。失焦、后台、旋转和触控取消暂停并清空输入。

## 枪械与经济

| 武器 | 价格 | 弹匣／备用 | 基础伤害 | 射击间隔 |
|---|---:|---:|---:|---:|
| 手枪 | 默认免费 | 12／60 | 20 | 0.24 秒 |
| 冲锋枪 | 1000 | 30／120 | 18 | 0.10 秒 |
| 步枪 | 2400 | 30／90 | 30 | 0.14 秒 |
| 狙击枪 | 3500 | 5／20 | 80 | 1.15 秒 |

生命 100，头部伤害两倍。护甲 600，降低 20% 身体伤害。开局资金 800；胜利 +3000、失败 +2000、击杀 +300、安包／拆包／每名人质救出 +300，上限 8000。武器模型复用 Tiny Strike 的 Glock、MP5、AK47、AWP，但游戏数值采用上表。

小地图只显示地形、自己、队友及任务。不会显示敌人位置；敌人血条只在受击且无遮挡时短暂显示。AI 依据视线、队友通报、最后见到的位置和公开任务事件行动。

## 工程与开源来源

```sh
npm install
npm run dev
npm run bake:maps # 地图定义修改后重新烘焙导航
npm run build
```

本地预览 `http://localhost:5180/`。正式构建输出自包含 `Bean-Frontier.html`，字体、模型、纹理生成器、导航数据和本地合成音频全部随包，不依赖 CDN。

- [Tiny Strike](https://github.com/guyz/tinystrike)：直接复用 ISC 许可的四种枪械 GLB 及墙面／地面／木箱／金属纹理生成器；来源、固定提交与文件清单见许可记录。
- [three-mesh-bvh](https://github.com/gkjohnson/three-mesh-bvh)：MIT，复杂地图碰撞与射线查询。
- [navcat](https://github.com/isaac-mason/navcat)：MIT，构建阶段导航网格及运行时查询。
- [ReGameDLL_CS](https://github.com/rehlds/ReGameDLL_CS)：经典人质和回合逻辑参考。
- [counter-strike-in-browser](https://github.com/StarKnightt/counter-strike-in-browser)：地图加载与材质实现参考。

第三方完整许可位于 `licenses/`。经典地图使用新代码和材质重做，不打包 Valve 原贴图或音效。

`window.render_game_to_text()` 提供只读地图、模式、阵营、回合、装备、姿态、区域及救援进度；`window.advanceTime(ms)` 提供固定步长验证。可修改的 `window.__gameTest` 仅在 `?test` 启用。自动化只连接 Codex 专用 `127.0.0.1:9333`，不操作用户常用 Chrome。
